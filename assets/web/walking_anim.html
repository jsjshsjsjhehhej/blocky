Walking Animation — scarica il Player R6 default, animarlo in Blender, poi rilascialo nel Catalog con il nome che vuoi.

Inizia i passi Nomi parti R6

Flusso completo

1

Scarica il Player R6 default

In Blocky Game Engine → Avatar Catalog premi Scarica modello Player R6. Ottieni un .obj beveled (come in Studio) + MTL + LEGGIMI.

2

Apri in Blender

File → Import → Wavefront (.obj). Tieni i nomi delle parti (o rinomina con spazi: Left Arm, ecc.).

3

Crea l’Action WalkingAnimation

Anima braccia e gambe (rotazione X = swing). L’Action deve chiamarsi esattamente WalkingAnimation.

4

Esporta GLB / FBX

Esporta con animazioni attive. Poi in Catalog: Importa WalkingAnimation.

5

Rilascia con il tuo nome

Scegli il nome pubblico (es. “Cool Walk”) e premi Rilascia Walking Animation. Si equipaggia in Play e appare nello Shop come [Walk].

L’import e il rilascio restano in Studio (dialog file nativi). Questa pagina è la guida web — aprila quando ti serve il flusso chiaro.
