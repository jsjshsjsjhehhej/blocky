Riferimento API

Seleziona un gruppo. Sintassi stile Roblox, sandbox senza io/os.

Tipi / costruttori

  • Vector3.new(x, y, z)Tabella {x,y,z} — anche .X .Y .Z in lettura
  • Color3.new(r, g, b)Canali 0…1
  • Instance.new("Part")
  • Instance.new("Sound")
  • Instance.new("BindableEvent", "Nome")
  • Instance.new("RemoteEvent", "Nome")

Workspace

  • workspace:Add(part)Aggiunge e restituisce Part live
  • workspace:FindFirstChild(name)Part live oppure nil
  • workspace:GetChildren()Lista snapshot delle parti
  • workspace:SetPartPosition(name, Vector3)
  • workspace:Raycast(origin, dir, maxDist?)→ {Instance, Position, Distance} o nil

Part live

  • .Name .Position .Size .CanCollide .ClassName
  • :SetPosition(v) · :GetPosition() · :Destroy() · :Explode([n])
  • .Touched:Connect(fn)fn(other, partName) quando il player entra nell’AABB
  • script.ParentSolo negli script attaccati a una Part

Game / servizi

  • game.RunService.Heartbeat:Connect(fn)fn(dt) ogni frame
  • game:GetService("RunService"|"SoundService"|"Particles"|"Players"|"Workspace"|"AntiLag")
  • AntiLag:SetMode("Auto"|"Off"|"Strong") · SetTargetFps(n) · GetLevel() · GetStats()
  • game.SoundService:Play(path [, looped]) · :Stop()
  • game.Animator:Play("Wave"|"Walk"|"Dance"|"Idle"|id)
  • game.Animator:SetWalkAnim(id) · SetJumpAnim(id) · Stop() · List()
  • game.Particles:Emit / Sparks / Smoke / Coins / Explode(pos [, count] [, color])

Humanoid / input

  • Humanoid.SetJumpEnabled(bool) · SetWalkEnabled
  • Humanoid.SetWalkSpeed(n) · SetJumpPower(n)
  • Humanoid.Get()→ JumpEnabled, WalkEnabled, WalkSpeed, JumpPower
  • UserInputService.DisableJump() / EnableJump()

task (facile, ordinato)

  • task.spawn(function() ... end)Avvia una routine
  • task.wait(secondi)Solo dentro task.spawn / task.delay
  • task.delay(sec, function)Esegue dopo N secondi
  • wait(sec)Alias di task.wait

Eventi

  • Events.Create / Connect / Fire / DisconnectAll
  • BindableEvent:Fire(...) · .Event:Connect(fn)
  • RemoteEvent:FireServer(string) · :FireAllClients(string)
  • .OnServerEvent:Connect · .OnClientEvent:ConnectPayload = stringa; LAN Host/Client

Anti-executor / sandbox

  • Bloccati: load require io os debug rawset setmetatable string.dump
  • API game / workspace congelata (non sovrascrivibile)
  • Clamp: WalkSpeed ≤ 28 · JumpPower ≤ 70 · Particles ≤ 128
  • Play: preferisce .bbc sigillato (BBCS)
  • Budget istruzioni + limite Heartbeat / Touched

Altro

  • print(...)
  • AnimateFrame(frame, Vector3)Keyframe su Model
  • pcall(fn)
  • Guida: assets/scripts/scripting_guide.lua

Esempio esplosione

Tocca la Part → particelle e sparisce.

explode_part.lua 
-- Blocco esplosivo · Test (F5)
local part = script.Parent
local esploso = false

part.Touched:Connect(function()
    if esploso then return end
    esploso = true
    print("BOOM!", part.Name)
    part:Explode()
end)
